`@antdv-next/pro` is an enterprise-grade **enhanced component library** built on top of [Antdv Next](https://github.com/antdv-next/antdv-next) (the Vue3 implementation of Ant Design), providing ready-to-use components for high-frequency Pro scenarios.

> Relationship with `antdv-next`: `antdv-next` is the base component library offering generic components such as Button, Table and Form; `@antdv-next/pro` sits on top of it with enhanced components for complex business scenarios (e.g. a customizable scrollbar container), sharing the same theme and token system.

## ✨ Features {#features}

- 🚀 **Enterprise-oriented**: ready-to-use components for Pro layouts such as long lists and dense navigation areas
- 🧩 **Native theming**: components participate in the `antdv-next` CSS-in-JS theme and token system, with `classes` / `styles` semantic customization
- 🛡 **TypeScript**: fully typed with predictable static types
- ⚙️ **Tree-shakable**: ESM modules consistent with `antdv-next`, loaded on demand
- 📦 **SSR-friendly**: supports server-side rendering and modern browsers

## 📦 Peer Dependencies {#peer-dependencies}

`@antdv-next/pro` declares `antdv-next` and `vue` as peer dependencies — install them yourself:

| Dependency | Minimum version |
| --- | --- |
| `vue` | >= 3.2.0 |
| `antdv-next` | >= 1.3.0 |
