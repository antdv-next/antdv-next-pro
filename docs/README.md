# Docs (source demos)

These are the source demos and markdown pages for the Pro components, migrated
from the main antdv-next monorepo. They are kept here as the source of truth for
the future Pro documentation site.

> Note: the `.vue` demo files still reference docs-framework helpers such as
> `@/components/semantic`, `@/composables/use-locale`, and the sibling
> `locales.ts`. Those helpers ship with the docs site framework and are **not**
> present in this repo yet — wire them up (or a VitePress/custom docs app) when
> building out the documentation site. For a runnable preview today, use the
> `playground` app at the repo root.

- `scrollbar/` — Scrollbar component (basic / visibility / controller / sider / semantic demos)
